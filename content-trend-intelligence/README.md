# Content Trend Intelligence — Web Dashboard

The web dashboard and API service for Content Trend Intelligence & Auto-Clipper, built with Next.js, React, Tailwind CSS, and Prisma.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

For full project documentation, architectural overview, and Python clipper pipeline instructions, refer to the [Root README.md](../README.md).
